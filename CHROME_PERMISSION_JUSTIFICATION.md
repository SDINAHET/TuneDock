# Chrome Web Store permission justification — TuneDock for Spotify

## Optional host access

Access to HTTPS pages is optional and requested only when the user enables the floating widget. It is used solely to inject the user-controlled TuneDock widget into the selected page. TuneDock does not inspect forms, passwords, browsing history or unrelated page content. No audio is captured, analyzed, recorded or transmitted.

French form text:

> L’accès aux pages HTTPS est facultatif et demandé uniquement lorsque l’utilisateur active le widget flottant. Il sert seulement à injecter le widget TuneDock contrôlé par l’utilisateur. TuneDock n’inspecte pas les formulaires, mots de passe, historique ou contenus sans rapport. Aucun son n’est capturé, analysé, enregistré ou transmis.
